# STK 영수증 OCR

주소: https://ocr-image.startruckkorea.com/

영수증을 촬영하거나 올리면 항목을 자동으로 채우고, 사람이 확인(리뷰)한 뒤 확정합니다.

- **브라우저 안에서 인식** — PaddleOCR 글줄 검출(ONNX Runtime Web)로 영수증을 찾아 바로 세우고, Tesseract.js(한국어 · 영어)로 두 번 읽어 항목마다 검증해 고릅니다. 인식 단계에서 이미지는 서버로 가지 않습니다.
- **실제 영수증 성능** — 휴대폰으로 찍은 영수증 8장(영수증 10건)의 핵심 6항목(사업자번호 · 거래일시 · 합계 · 공급가액 · 부가세 · 승인번호) 93%. 가로로 찍힌 사진은 자동으로 세우고, 한 사진의 여러 영수증은 따로 나눕니다.
- **인식 항목** — 가맹점(상호 · 사업자등록번호 · 대표자 · 주소 · 전화), 거래(일시 · 영수증번호 · POS), 금액(공급가액 · 부가세 · 면세 · 봉사료 · 할인 · 합계 · 받은금액 · 거스름돈), 결제(수단 · 카드사 · 신용/체크 · 카드번호 · 할부 · 승인번호 · 승인일시 · 승인금액 · 가맹점번호 · 매입사), 현금 · 계좌(현금영수증 · 은행 · 계좌번호 · 예금주), 품목(상품명 · 단가 · 수량 · 금액).
- **리뷰** — 항목마다 어떻게 찾았는지(자동 인식 · 모양으로 찾음 · 계산 · 미인식) 표시. 의심 항목(낮은 신뢰도 · 깨진 글자 · 사업자번호 검증 실패 · 체크카드 할부 등)은 「확인」 해야 하고, 검산(공급가액 + 부가세 = 합계 · 품목 합계 · 승인금액 · 부가세 10%)이 어긋나면 고치거나 확인해야 확정됩니다.
- **로그인 · 저장** — 회사 Microsoft 계정으로 로그인(다른 STK 시스템과 같은 앱 등록). 확정하면 SharePoint STK-DB 사이트 `AttachedFiles › OCR_AttachedFiles › YYYY-MM › YYYYMMDD-HHmmss_아이디_상호/` 에 원본 사진(`receipt.*`)과 리뷰 결과(`result.json`)를 저장합니다. 4MB 가 넘는 사진은 나눠 올립니다. 저장에 실패하면 목록에서 「다시 저장」.
- **내보내기** — 확정한 영수증 목록은 이 브라우저에도 남으며 Excel(영수증 · 품목 두 시트) · JSON 으로 내보냅니다. 가려지지 않은 카드번호는 앞 4 · 뒤 4 만 남기고 가립니다.

파일: `index.html`(앱 — 파서 · 비전 모듈 포함) · `parser.js` · `vision.js`(같은 코드, 테스트용) · `models/`(PaddleOCR 모델, 출처는 `models/NOTICE.md`).
